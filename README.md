# Peptra Bio

A modern, high-performance web platform and catalog for research peptides, biochemical standards, and analytical verification.

## Features

- **Scientific Catalog**: Detailed peptide specifications, molecular weights, receptor pathways, and purity standards.
- **Analytical COA Verification System**: Batch-level HPLC & Mass Spectrometry Certificate of Analysis lookup and request tool.
- **Scientific Research Hub**: In-depth monograph articles, comparative breakdowns, and interactive Table of Contents.
- **Support & Ticket System**: Integrated customer and lab inquiry support ticketing workflow with Supabase.
- **Cart & Checkout**: Multi-currency dynamic converter, real-time drawer, and responsive shopping workflows.
- **Mobile-First UX**: Responsive controls with scroll-activated sticky buy bars and touch-friendly controls.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, Orbitron & Inter Typography, Custom Glassmorphism
- **Database / Auth**: Supabase
- **Icons**: Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
